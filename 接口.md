```python
# 获取实时仪表信息
API_ENDPOINT_GetYiBiaoInfo = "/shoufeizjj3/api/WxProgramApi/GetYiBiaoInfo?Type=SS"
# 获取仪表数据
API_ENDPOINT_GetDataList = "/shoufeizjj3/api/WxProgramApi/GetDataList"
```

请求url就是{API_BASE_URL}{API_ENDPOINT_xxxx}
